# HƯỚNG DẪN DÀNH CHO CLAUDE CODE (CLAUDE.MD)
================================================================================
Dự án: NextAI VPN Platform & Residential Gateway Mesh (Chuẩn V2.1)
================================================================================

Claude Code BẮT BUỘC tuân thủ các nguyên tắc sau:
1. Đọc [AGENTS.md](AGENTS.md) trước khi thực hiện bất kỳ lệnh nào.
2. Đọc [Docs/rules.md](Docs/rules.md) để tuân thủ quy chuẩn viết mã (song ngữ VI + EN, không dùng thư viện deprecated).
3. Tuân thủ ID nhiệm vụ và cấu trúc Task Graph.
4. Kiểm tra file khóa `.ai/locks.json` trước khi sửa file.
5. Kiểm tra trạng thái Git (`git status`) trước và sau khi thực hiện công việc.
6. Cập nhật tiến độ vào [UPDATETODOS.md](UPDATETODOS.md) và [TASK_LOG.md](TASK_LOG.md).
7. Mọi câu hỏi hoặc thông số cần user cung cấp (API key, credentials) phải ghi nhận vào [Tasksrequiring.md](Tasksrequiring.md).
